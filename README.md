# Beyond Economic Success — Streamlit App v16

A Streamlit research companion for the WVS Wave 7 life-satisfaction project.

## v16 updates

- Added **Extra Insights**, a separate exploratory page with three weighted descriptive charts: age patterns across Q49/Q50/Q48, gender differences by age group, and country-level gender gaps using country/region names.
- The Extra Insights page clearly distinguishes these descriptive analyses from the predictive machine-learning model. No new ML model is trained for this page.
- Added an image viewer to charts throughout the app. Tap/click a chart preview to open the viewer; use pinch gestures on touchscreens or the + / − controls to zoom, drag to pan, and Reset/Close to return.
- Preserved the existing Warm Sun Modern design and each page's own header/title/intro with navigation embedded in the page header.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Prediction model

The Prediction page uses a separately trained reduced-input Random Forest with 20 inputs: 19 survey questions plus Country/region. It uses the fitted hierarchical imputation statistics and one-hot Country encoder saved with the model artifact.

The Notebook 05a feature-count experiment found that the Top 30 configuration performed slightly better than Top 20 (5-fold CV R² 0.4533 vs. 0.4460). The interactive version uses a reduced input set for ease of completion; its predictions are not generated by the Top 30 model. The App deploys a 100-tree sub-ensemble from a 200-tree reduced-input fit to keep the artifact smaller.

The supplied test split was used in earlier project analyses, so the App's test metrics are supplementary rather than a fresh independent evaluation. Predictions are statistical estimates, not causal or definitive assessments of individual wellbeing.

## Extra Insights interpretation

The additional age/gender/country comparisons use WVS Wave 7 descriptive summaries with `W_WEIGHT`. They are cross-sectional associations, not causal effects. Country-level differences are Female weighted mean Q49 minus Male weighted mean Q49; positive values indicate a higher female mean and negative values a higher male mean.
